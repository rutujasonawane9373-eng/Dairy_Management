Welcome to the Dairy Management System

This system helps dairy cooperative societies manage their daily operations in one place. It records milk collected from every farmer each day, notes the fat and SNF (% non-fat solids) quality of the milk, calculates payments and generates reports.

The project is being developed step-by-step as a college course project. Every page you see here demonstrates one practical assignment which is documented in docs/assignment-mapping.md.

Project Modules (Assignment 16 - Complete Integration)

The project is built from four parts. Each part keeps its own assignment files; the list below is the one place where all of them can be opened. Start the server you need first - each note says the command.

1. Static website (Assignments 1 - 7 and 11)

HTML, CSS and the single script js/main.js. This is the site you are reading now - no server is needed, it opens directly in the browser.

Open the Dashboard

2. React single page application (Assignments 8, 9, 10)

Run cd react-app && npm run dev, then open http://localhost:5173/ (components, hooks and the fetch() demo).

3. PHP pages and PHP + MySQL CRUD (Assignments 12, 13)

Start PHP from the project root (php -S localhost:8000), then open PHP Home and PHP + MySQL CRUD. Both use the database from database/schema.sql.

4. Node.js server and REST API (Assignments 14, 15)

Run cd node-backend && npm start, then open the Express home page, GET /api/farmers, and this same website served by Node.js at /frontend/index.html.

One database, two back-ends

  • Assignment 13 (PHP + MySQLi) and Assignment 15 (Node.js + mysql2) both read and write the same table: dairy_management.farmers.
  • The MySQL password exists only in php/db-crud/db-config.php and node-backend/db-config.js - both are gitignored, so it is never committed.
  • The map of every assignment is in docs/assignment-mapping.md.
